# 研股 UI v5 · 对话式研究

这份交付是可点击的独立设计原型，尚未集成正式前端、后端、模型或市场数据。直接在浏览器打开 `index.html` 即可预览。证券、走势图与研究内容均为交互演示。

## 本版设计

- 白色内容底、浅灰导航、石墨文字、低饱和靛紫操作；核心色为 #FFFFFF、#F6F6F8、#252630、#777985、#6860BD、#3E796C。
- 字体采用 PingFang SC / Hiragino Sans GB / 系统无衬线，主区 828px 阅读宽度，以正文、图表和引用构成层级。
- 延续两栏，侧边栏负责历史与导航；主区以自然语言回答为主，阶段与角色报告按需展开。
- 只保留一张主要图表产物，不在首屏重复铺设评级卡、流程条、多报告表格。
- 临时证据抽屉不占永久第三栏；在窄屏收起桌面导航，保留阅读和追问。

## 可体验的交互

新建研究和返回当前研究、查看研究过程、切换四类分析师报告、展开多空分歧、查看风险与依据、点选追问、新问题输入、搜索演示记录与键盘关闭抽屉。新增问题发送时明确提示这是原型，不伪装成真实模型响应。

本稿中的完整报告以临时阅读面板示意；正式产品可另做独立报告阅读页。历史记录、评测、上传与设置有明确的演示边界，未实现完整业务操作。未加入外部分享或交易执行。

## 检查范围

使用本地 Chrome 实际渲染，检查桌面/窄屏横向溢出、报告抽屉、角色切换、Escape、讨论展开、追问填入、新建研究、依据面板和窄屏导航隐藏，10 项通过。截图经视觉检查后修正了辅助文字对比度、手机标题换行和抽屉过渡状态。该检查不代表后端或真实 Agent 功能通过验收。
