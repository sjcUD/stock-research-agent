# 研股 UI v4：TradingAgents 聊天研究工作区

日期：2026-10-31。状态：高保真概念稿，未实现前端。图中内容为演示，不是实际行情或研究结论。

## 布局与视觉

保留侧边栏与主聊天区两栏。侧边栏包括新建研究、研究对话、研究报告、决策评测和历史研究。白色 #FFFFFF、冷灰 #F5F7FB、深蓝 #172A46、操作蓝 #2858D9；少量青色与琥珀色表达完成或缺数据。中文使用系统黑体，表格左对齐，数字按列对齐。

这版收敛到 TradingAgents 的单股研究链，而不是完整持仓管理平台：分析师研究、多空讨论、交易提案、风险评估、最终报告。提案不自动执行交易。

## 信息层级

1. 顶部明确证券、市场、研究日期与演示状态。
2. 对话中显示用户问题，随后为可折叠研究阶段。
3. 先看综合结论、研究评级与不确定性，再看多空分歧。
4. 分析师报告以基本面、技术面、新闻、市场情绪切换；缺样本明确标注，不伪造分数。
5. 风险评估摘要可以展开；点击引用临时打开证据，不增加固定第三栏。
6. 查看完整报告进入阅读页；聊天内继续追问沿用当前证券与日期，变更范围时明确提示。

## 原项目与新增设计

角色和阶段来自已核查的 TradingAgents 固定版本；聊天会话、前端交互、统一证据引用是 Java 产品新增设计。图中不宣称原仓库已经实现这些界面或证据协议。研究评级仅为演示内容。
