# 研股 UI 与交互 v3

状态：设计概念稿，尚未实现。沿用已确定的 A 股优先与 Spring AI Alibaba 技术方向。

## 视觉与布局

两栏布局：左侧导航与最近研究；右侧为完整聊天工作区。冷白背景 #F5F7FB、白色内容面、深蓝文字 #172A46、钴蓝操作 #2858D9，青色仅用于状态。中文采用苹方或系统黑体，数值对齐，不使用上涨红绿充当操作色。

研究结论、表格、图表和引用嵌入聊天。过程用折叠的阶段记录展示；证据用临时抽屉；长报告单独页面。图中所有证券数值均为演示数据，不代表实际行情。

## 导航与入口

- 研究对话：自然语言发起选股、单股分析与股票对比，支持上传资料。
- 自选股票：收藏研究对象，并从选中股票发起比较。
- 我的组合：查看持仓、分析集中度与风险；修改前显示变更确认。
- 持续跟踪：管理目标、规则、频率、通知与暂停状态。
- 研究报告：查看历史报告，按股票与日期查找。

## 关键行为

1. 清楚的问题直接开始；仅在证券身份、日期或条件有歧义时追问。
2. 运行中展示当前阶段和停止入口；刷新或再次进入可恢复查看进展。
3. 点击来源打开临时证据抽屉，包含原文、披露日期、采集时点和对应结论；关闭后保留阅读位置。
4. 查看报告进入独立阅读页；返回时回到原对话。表格与报告复用同一研究产物。
5. 后续追问继承已确认标的和约束；改变日期或口径时明确标注新范围。
6. 收藏、组合修改和跟踪创建展示实际写入内容，确认后提交；不提供券商下单。
7. 失败保留已核实内容；区分缺失数据、部分完成、用户停止与等待确认，不能全部标成功。
8. 跟踪有变化才通知；检查失败独立显示，不当作无变化。

## 设计取舍

不采用固定三栏与首页行情墙，保证对话和对比表可读宽度；避免功能入口全部堆在聊天输入框中。执行详情承载阶段、工具和停止原因；预算与内部框架不占据主要研究界面。
